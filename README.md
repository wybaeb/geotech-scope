# ГеоТех · конструктор объёма работ

Одна страница, целиком зашифрованная: gzip → AES-256-GCM, ключ выводится из пароля
(PBKDF2-SHA256, 200 000 итераций). Расшифровка происходит в браузере, пароль никуда
не отправляется, в репозитории лежит только шифротекст.

Пароль — у владельца. Исходники конструктора и сборщик в репозиторий не попадают.
